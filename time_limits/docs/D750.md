# D750 1.15 movie time-limit table

主模块：`b1010_115a.bin`（官方 `D750_0115.bin` 解密后，模块 SHA-256
`faada7fe2bcc90fef8877fae37965ee836f867b08f5736c67c5266b1f82937fd`）。

## 表

- 偏移：`0x2F2104`
- 30 × u32 毫秒，表后哨兵 `0x2F217C = 58348 (0xE3EC)`
- stock 值：

```text
600000, 1200000, 600000, 1200000, 1200000, 1799000, 1200000, 1799000,
1200000, 1799000, 1200000, 1799000, 1200000, 1799000, 1799000, 1799000,
1799000, 1799000, 1799000, 1799000, 1799000, 1799000, 1799000, 1799000,
1799000, 1799000, 1799000, 1799000, 1799000, 1799000
```

前两项 600000 对应 1080p60/50p 的 HQ 10 min；其余 20 min / 29:59。

## Profile

`profiles/d750_0115_time59.json` 把 30 项全部改成 `3599000`（59:59）。

```powershell
python time_limits\time_limit_patch.py --module b1010_115a.bin `
  --profile time_limits\profiles\d750_0115_time59.json --check
```

## 限制

- 4 GB 单文件上限不解除；64 Mbps 下仍在约 8–9 分钟封口。
- 59:59 只在低码率时才有意义（FAT32 下 59:59 需 ≤9.4 Mbps）。
