## 60p / 50p 都是 64/60

主仓库的 `d7200_hq64.json` 只改 1080p60 HQ；`profiles/d7200_hq64_50p.json`
把 60p 和 50p 的 HQ 行都改成 64/60，并替换 60p/50p 标签。

```powershell
python nikon_movie_patch.py --module b1230_104.bin `
  --config time_limits\profiles\d7200_hq64_50p.json `
  --out b1230_104.hq64_50p.bin

python time_limits\time_limit_patch.py --module b1230_104.hq64_50p.bin `
  --profile time_limits\profiles\d7200_0104_time59.json `
  --out b1230_104.hq64_50p.time59.bin
```

## 限制

- **4 GB 单文件上限不解除**：实测封口约 `0xFC000000`（4 GiB − 64 MiB），
  exFAT 也一样；64 Mbps 约 8:48，42 Mbps 约 13:25，24 Mbps 约 23:29。
- **相机回放还依赖 `udta/NCDT`**：长文件没有 `NCDT` 时相机报“无法显示该文件”，
  见 [ANALYSIS_4740_4741.md](ANALYSIS_4740_4741.md) 与
  [KNOWN_ISSUES.md](../../KNOWN_ISSUES.md)。
- 50p 64 Mbps 只做了容器级验证，**未真机验证**；60p 64 Mbps 已由主仓库真机验证。
- 每个档位的单段最大时长见 [MAX_DURATIONS.md](MAX_DURATIONS.md)。
